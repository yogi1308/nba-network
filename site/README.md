# NBA Network

**[Live site →](https://nba-network.vercel.app)**

A network graph of every player in NBA history. Each player is a node, and if two players were ever teammates, there is an undirected, weighted edge connecting them. (weighted by how many seasons they played together, not currently used in any metric, but might be useful someday).

It's simple and intuitive. It does what it says (at least I think so). It can 

## Features

- 🔍 Search for any player
- 🕸️ Filter the network by decade or team
- 🔗 Find the shortest path between two players
- 📏 Find a path of a specified length or length range
- 📊 Player and network metrics

A write-up on more interesting insights and metrics like centrality, betweenness, and what they tell us about the NBA, is coming soon (hopefully).
